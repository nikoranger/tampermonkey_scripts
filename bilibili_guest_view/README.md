# B 站游客播放增强（Tampermonkey）

一个轻量的页面增强脚本：自动关闭登录弹层、隐藏登录与 App 推广提示，并在弹层关闭后恢复页面滚动。

它面向**无需登录即可访问的公开内容**，不会伪造登录状态，也不会绕过会员、付费、DRM 或服务端登录校验。

## 功能

- 自动关闭 B 站视频页偶尔弹出的登录弹层；
- 对未知登录弹层提供通用兜底识别：同时检查 ARIA、登录文案和弹层尺寸，降低网站改版后失效的概率；
- 用户主动点击“登录”时，保留下一个登录弹层，避免影响正常登录；
- 临时隐藏过的登录弹层会在用户发起登录时恢复显示，不会被兜底样式永久压住；
- 隐藏侧栏、“登录后更精彩”、头像悬浮登录面板等登录提示；
- 可选隐藏 App 下载、打开 App 和“用手机观看”推广提示，默认关闭；
- 关闭弹层后解除页面滚动锁定；
- 所有开关都可在 Tampermonkey 菜单中调整，并保存在本地。

## 不包含的能力

本脚本**不会**：

- 写入或修改 Cookie、`access_key`、登录票据；
- 伪造用户信息或调用需要账号权限的接口；
- 修改播放器鉴权、清晰度列表、视频地址或请求参数；
- 解锁大会员、付费课程、付费番剧、充电专属或 DRM 内容；
- 在视频被网站暂停后自动恢复播放。

因此：

- 如果匿名请求已经能取得视频流，脚本只负责减少登录弹层干扰；
- 如果服务端明确要求登录、会员或付费，播放仍会被正常拦截；
- 清晰度上限仍由网站对游客的规则决定。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 打开 [`guest-view.user.js`](guest-view.user.js)，或把文件拖进浏览器；
3. 在 Tampermonkey 安装页确认安装。

也可以手动新建脚本，把 `guest-view.user.js` 的全部内容粘贴进去保存。

## 油猴菜单

点击 Tampermonkey 扩展图标 → 本脚本名称：

- **自动关闭登录弹层：开/关**；
- **隐藏登录提示：开/关**；
- **隐藏 App 下载提示：开/关** —— 默认关闭，开启后清理移动版、桌面版 App 推广；
- **关闭弹层后恢复滚动：开/关**；
- **立即关闭当前登录弹层** —— 自动关闭关闭时也可手动使用；
- **检测当前页面登录弹层** —— 在控制台输出匹配到的选择器、关闭按钮和弹层摘要；
- **调试日志：开/关**。

菜单设置保存在 Tampermonkey 本地存储中，不会上传。

## 已知限制

- 已知登录弹层使用固定选择器（例如 `.bili-mini-mask`）；完全未知的弹层还会经过通用兜底判断，但过小、无登录语义或位于 Shadow DOM 中的弹层仍可能识别不到；
- 某些登录弹层出现前，播放器会先被网站暂停。脚本不会自动续播，需要手动点击播放；
- 移动版页面和桌面版页面的提示结构可能不同，脚本会尽力兼容，但不保证每个实验性布局都能识别；
- 页面刚打开时弹层可能短暂闪现；
- 不处理 Shadow DOM 内的弹层；
- 请遵守目标网站的使用条款，仅在你有权访问的内容上使用。

## 调试

如果弹层没有被关闭：

1. 使用油猴菜单中的“检测当前页面登录弹层”，查看是否识别到目标元素；
2. 打开“调试日志”，在浏览器控制台筛选 `[bili-guest-view]`；
3. 使用菜单“立即关闭当前登录弹层”测试一次；
4. 若仍无效，记录控制台中的选择器、弹层类名和关闭按钮结构，再更新脚本选择器。

脚本不会发起额外的网络请求，也不会收集或上传页面数据。
