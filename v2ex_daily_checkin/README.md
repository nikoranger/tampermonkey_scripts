# V2EX 每日自动签到（Tampermonkey）

访问 V2EX 时自动检查并领取账号的每日登录奖励。脚本只在已登录的浏览器页面内操作，不读取、导出或代填账号密码。

## 功能

- 打开或刷新 V2EX 页面后自动检查签到，不要求手动进入任务页；
- 同时兼容旧版“领取链接”和新版 `onclick` 领取按钮；
- 使用单次领取链接完成签到，并在领取后重新读取任务页复核结果；
- 同一自然日内成功后不再重复请求；
- 瞬时网络失败会自动重试一次；连续失败后冷却 2 分钟，避免每次翻页都反复请求；
- 未登录或登录失效时不尝试绕过登录；
- 右下角提示签到结果，并提供任务页入口；
- 支持从 Tampermonkey 菜单关闭自动签到、立即检查和查看今日状态。

脚本按 `Asia/Shanghai` 时区判断日期。V2EX 页面结构变化后，如果找不到领取入口，脚本会提示手动打开任务页确认。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 点击 [`v2ex-daily-checkin.user.js`](v2ex-daily-checkin.user.js)，在 GitHub 页面点击 **Raw**；也可以直接把文件拖进浏览器；
3. 在 Tampermonkey 安装页确认安装；
4. 登录 V2EX，然后打开或刷新任意 V2EX 页面。

安装完成后，可在 Tampermonkey 扩展菜单中看到：

- **自动签到：开/关（点击切换）**；
- **立即检查并领取今日签到**；
- **查看今日签到状态**。

## 工作方式

1. 页面加载后等待约 1.2 秒，确认当前页面没有明显的未登录状态；
2. 在同一站点内读取 `/mission/daily`，查找页面中的一次性领取链接；
3. 对找到的 `/mission/daily/redeem?once=...` 地址发起同源请求；
4. 再次读取任务页，确认领取按钮已消失后记录签到成功。

脚本只向 V2EX 当前站点发起同源请求，不会把 Cookie、页面内容或账号信息发送到其他服务器。

## 注意事项

- 需要先在浏览器中正常登录 V2EX；
- 脚本不会绕过登录、验证码、风控或站点限制；
- 如果脚本状态被清除，但账号当天已经签到，重新检查时页面不会出现领取按钮，脚本会按已签到处理；
- 站点改版可能导致领取入口无法识别，此时可从提示条或油猴菜单打开任务页手动确认；
- 请遵守目标站点的使用条款，仅用于自己的账号。
